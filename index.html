Цена СУГ по формуле: DAP / FCA

DAP = [вес1 × (котировка1 − дифф.1) + … + вес4 × (котировка4 − дифф.4)] / компонент 1; FCA = DAP − компонент 2. Котировки в долларах (AFEI) переводятся в юани по курсу месяца.

Дифф. и компонент 2 — одно значение на весь год: транспорт по Китаю берется средним за 2026 год. Расчет — по месяцам 2026 года. Варианты для сравнения сохраняются в этом браузере.
